// Диапазон АЦП задают регистры 0 и 1 (А * 10). Границы ЦАП — регистры 17 и 18.
// CLSLPC_CalibrateADC пишет N, D, B. Знаменатель D = 1000, числитель N = K * 1000.
// Kamp (28/29/30) и шунт (6) не записывает.
// CLSLPC_CalibrateDAC, CLSLPC_CalibrateADC, CLSLPC_CalibrateId и CLSLPC_VerifyId
// показывают регистры регулятора 49-57 и слежение ошибки 73.
// Скрипт эти регистры не изменяет. Перед проходом нужно дважды подтвердить состояние.
// CLSLPC_CalibrateId пишет P2, P1, P0.
// Прошивка выбирается одним флагом clslpc_Compatibility (0 — IAR, 1 — Atolic).
// По умолчанию 1. Можно задать после include: значение подхватят LSLPC_Start и CLSLPC_TekInit.
